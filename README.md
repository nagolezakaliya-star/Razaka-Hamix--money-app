# HAMIX MONEY APP 💛

A mobile money and business management app for Uganda.

## What HAMIX Does
1. Create account with phone number
2. Save money daily / weekly
3. Send money to friends and family
4. Manage small business money

- Login Screen
- Home Screen - Balance UGX 250,000
- Send Money Screen
